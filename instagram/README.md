# Instagram files

Used by the Instagram skill pack (/ig-reel, /ig-caption, /ig-audit and others).

- `voice.md`: how I talk, so scripts sound like me
- `log.md`: history of posted reels, used by /ig-audit
- `reels/`: each reel's script and caption

At the start of a new session, ask Claude to copy `voice.md` and `log.md` into `~/.claude/instagram/` so the skills can find them.
